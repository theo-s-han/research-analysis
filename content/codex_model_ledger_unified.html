결론

작업이 명확하면 Luna Max, 문제 정의부터 필요하면 Sol.

기본
Luna Max
일을 잘 정의해서 주면 매우 효율적입니다. 해야 할 일, 대상 기능, 기대 결과가 명확한 검증·수정·자동화 작업에 적합합니다. 반대로 무엇을 해야 하는지, 어디가 문제인지부터 모델이 판단해야 하는 작업에는 적합하지 않습니다. 그런 작업이라면 Luna에서 실패할 때까지 기다리기보다 처음부터 Sol을 선택하는 편이 낫습니다.
원인 분석
Sol Medium
문제는 보이지만 원인이나 해결 방향이 명확하지 않을 때 사용합니다. 예: 테스트가 왜 실패하는지, 어떤 파일이 원인인지, 여러 로그 중 무엇을 먼저 봐야 하는지부터 판단해야 하는 작업. 7.2~8.8× / Index 62로 비용은 크게 올라가지만 Luna Max보다 문제 탐색과 판단이 필요한 작업에 적합합니다.
복잡한 분석
Sol High
여러 파일·로그·기능이 얽혀 있거나, 원인 후보가 많고 영향 범위까지 판단해야 하는 문제에 사용합니다. 10.0~12.5× / Index 64. Sol Medium보다 한 단계 높은 분석이 필요할 때 선택하면 됩니다.
최후 수단
Sol Max
일반적인 기본 모델로 쓰기에는 비용이 너무 큽니다. 16.5~20.6×인데 Index는 65로 Sol High보다 1점 높습니다. Sol High에서도 해결되지 않거나 한 번의 정확한 분석이 매우 중요한 경우에만 사용하는 편이 합리적입니다.
조건부
Terra Max
Luna Max보다 더 많은 판단이 필요하지만 Sol까지 올리기에는 한도 비용이 부담스러운 경우의 중간 선택지입니다. 6.0× / Index 60. 다만 Sol Medium과 비용 차이가 크지 않고 성능은 낮아 주력 모델이라기보다 비용 제한이 있을 때의 선택지에 가깝습니다.
사실상 제외
Luna Medium / High
비용은 낮지만 Index가 42 / 52로 낮습니다. 검증 업무에서 모델의 판단 결과를 다시 사람이 확인해야 한다면 절약되는 한도보다 재확인 비용이 더 커질 수 있습니다. Luna를 쓸 정도로 작업이 명확하다면 Luna Max를 사용하는 편이 낫습니다.
사실상 제외
Luna XHigh
High 대비 비용은 0.60× → 0.80×로 늘지만 Index는 52 → 53입니다. Luna 계열을 사용할 상황이라면 Luna Max로 바로 올리는 편이 단순하고 안정적입니다.
사실상 제외
Terra Medium / High / XHigh
비용은 2.0~4.16×인데 Index는 48~56으로 Luna Max의 57보다 낮습니다. 현재 표의 비용·시간·점수 조합만 보면 중간 단계를 선택할 이점이 작습니다.
사실상 제외
Sol XHigh
Sol High보다 비싸고(12.4~15.4×), 느리고(7.4분), Index도 낮습니다(63 vs 64). DeepSWE 점수만 특별히 우선하는 경우가 아니라면 Sol High를 사용하는 편이 낫습니다.
이전 모델
GPT-5.5 / GPT-5.4
신규 작업에서는 GPT-5.6 계열보다 우선할 이유가 적습니다. GPT-5.5 xhigh는 Index 61 / 10.1분, GPT-5.4 medium은 Index 39입니다. 기존 결과 재현이나 호환성 확인이 필요한 경우에만 남겨두는 편이 좋습니다.
외부 참고
Fable 5 / Grok 4.5
Codex에서 직접 선택하는 모델은 아닙니다. Fable 5는 Index 66으로 성능 상한 비교에, Grok 4.5는 Index 64 · 3.6M tokens · $2.59/task로 외부 에이전트의 비용 효율 비교에 참고할 만합니다.
※ “사실상 제외”는 모델을 사용할 수 없다는 뜻이 아니라, 현재 표에서 인접 모델 대비 비용·시간·점수 조합의 선택 이점이 작다는 의미입니다.
