Opus 5.5 High

Opus 5.5 reasoning은 별도 표로 분리하지 않는다. 전체 비교 안에서 보면 Medium 51 / $1.34 → High 54 / $1.82 → xHigh 56 / $3.46 → Max 58 / $5.98로 올라간다. CursorBench 4.0에서는 High와 xHigh가 모두 56.0%인데 비용이 $3.97 → $6.98로 증가한다. 따라서 이 보고서의 코딩 권장 설정은 High, 가격 대비 성능 선택은 Medium, 최고 성능 선택은 Max로 구분한다. 다른 코딩 작업에서 High와 xHigh가 항상 동등하다는 뜻은 아니다.

'미측정'은 성능이 0이라는 뜻이 아니라 동일 CursorBench 4.0 결과가 공개되지 않은 경우다. AA Intelligence·AA-Briefcase·AutomationBench·Terminal-Bench·SciCode·Cost/task는 같은 Artificial Analysis Intelligence Index 평가 체계의 공개값으로 비교했다. 이 표의 Opus 5.5 AA 수치는 Artificial Analysis의 'Adaptive Reasoning, Default Fallback' 조건을 따른다. 아래 Coding Agent Index의 Terminal-Bench는 에이전트·harness가 포함된 별도 평가이므로 수치가 다르다.

기존 모델 정리

Claude Opus 5 사실상 대체

Opus 5 Max는 AA Intelligence 51 / $5.86. Opus 5.5 Medium이 같은 51점을 $1.34에 제공하고 CursorBench도 52.5% vs 46.6%로 높다. 일반적으로 5를 유지할 이유가 크게 줄었다.

Claude Fable 5.1 비용 기준 재평가

Fable Max는 53 / $7.63, Opus 5.5 High는 54 / $1.82. AA 종합점수와 비용만 보면 Opus 5.5 High가 유리하다. 다만 Anthropic은 어려운 추론·장기 에이전트 작업 또는 Opus 5.5가 자체 평가에서 부족한 경우 Fable 5.1을 여전히 권장한다.

GPT-6 Astra 직접 경쟁

성능대가 가장 가까운 외부 비교군. Opus 5.5는 Medium·High에서 가격 경쟁력이 강하고, 이 표에서는 Astra Max가 Opus 5.5 High보다 Automation과 AA Terminal 점수가 높다.

운영 결론

작업 대표 선택 이유
비용을 낮추면서 상위 모델 판단력이 필요함 Opus 5.5 Medium 이전 Opus 5 Max와 같은 AA Intelligence 51을 약 77% 낮은 task 비용으로 제공. Astra High와도 같은 51점인데 $1.34 vs $1.73으로 더 저렴하다.
일반적인 어려운 코딩 · Claude Code 권장 설정 Opus 5.5 High CursorBench 56.0% / $3.97. 이 CursorBench 평가에서 xHigh와 점수는 같고 비용은 낮다. AA Intelligence 54로 Astra Max 53보다 높으면서 AA task 비용도 $1.82 vs $3.26으로 낮다.
일반 추론을 더 끌어올리고 싶음 Opus 5.5 xHigh AA Intelligence 56. High보다 종합점수는 높지만 CursorBench 결과는 같았다. 더 깊은 추론이 필요한 작업에서 고려하되 실제 작업으로 검증해야 한다.
비용보다 최고 성공률이 중요함 Opus 5.5 Max AA Intelligence 58, Coding Agent Index 66, CursorBench 57.8%. 현재 최고 성능 구간이지만 High 대비 추가 비용이 매우 커 기본값으로는 과하다.
Astra와 선택이 고민됨 성능대와 작업 성격으로 선택 AA 종합점수 51점에서는 Opus Medium ↔ Astra High, 53~54점대에서는 Opus High ↔ Astra Max가 비교 대상이다. Opus는 AA-Briefcase와 Coding Agent Index에서, Astra는 AA Automation·일부 Terminal에서 상대적으로 강하다. Coding Agent Index는 Claude Code와 Codex의 에이전트 환경도 함께 비교한 결과다.
