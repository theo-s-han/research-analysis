결론

Argon 대비 성능 개선, 비용 절감 모델과는 다른 위치

같은 High·AA v5.0에서 종합 점수 50.4 → 59.4(+9.0점). FrontierCode 2.0은 +14.9%p, Terminal-Bench 4.0은 +8.1%p 개선. 표준 작업 비용은 $7.68 → $7.76로 비슷한 수준이어서, 사용 권한과 호환성이 같다면 Argon 대신 Carbon을 우선 검증할 근거.

다만 Carbon 비용이 조금 더 높아 Argon을 “더 비싸고 성능도 낮은 모델”로 일괄 분류할 수는 없음. 지식 문답의 환각률도 4.3% → 11.4%로 상승. 정답률 향상과 환각률 개선을 같은 말로 취급하면 안 됨.

종합 1위가 모든 개발 작업의 1위는 아님

Carbon High의 AA 59.4는 Opus Max 58.4·Astra Max 56.9보다 높지만, 차이가 작고 통계적 확정 우위로 단정할 수 없음. 저장소 수정 FrontierCode 2.0에서는 Opus 46.4%·Astra 42.4%가 Carbon 40.6%보다 높음.

에서도 Claude Code Opus가 Index 선두, Codex Sol은 비용 우위. Sol Max 대비 Carbon의 종합 평가 비용은 약 6.1배. 기존 모델을 일괄 대체할 근거는 부족.

현재 환경 유지, 공개 후 동일 과제로 검증

지금은 기존 Codex·Claude Code·Gemini 환경 유지. Carbon은 아직 일반 공개 전이며, AA High 평가를 사용자 기본 설정으로 강제할 단계가 아님. 권한 확보 후 저장소 수정·장시간 원인 분석·보안 패치를 같은 과제로 비교하고, 정확도·재시도·완료 비용·사용량 제한을 함께 확인할 필요.

Carbon은 가중치 비공개 모델. AA 공개 사양은 Context 1M, 텍스트·이미지·음성·영상 입력과 텍스트 출력. 대규모 문맥 수용량과 실제 대규모 코드 작업 성공률은 별개.
