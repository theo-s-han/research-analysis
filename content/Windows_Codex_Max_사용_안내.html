Windows Codex 앱에서 Max 사용하기

아래 요청 문구를 복사해 Codex의 새 작업에 붙여 넣으면 됩니다. Codex가 이 PC의 실제 모델 지원 여부를 확인한 뒤, 가능한 경우에만 Max 선택 항목을 설정합니다.

대상
Windows의 ChatGPT Desktop / Codex
소요 시간
약 2~3분
필요 사항
Codex 로그인 및 로컬 설정 파일 접근
마지막 검토
2026-09-15
01

방법

  1. 1.Windows Codex 앱에서 새 작업을 엽니다.
  2. 2.아래 요청 문구 복사 버튼을 누른 뒤, 새 작업에 붙여 넣고 실행합니다.
  3. 3.Codex가 안내하면 앱을 완전히 종료 후 다시 열고, 새 작업에서 reasoning effort에 Max가 보이는지 확인합니다.
02

Codex에 보낼 문구

Windows Codex Desktop · Max 활성화 요청 
Windows Codex Desktop에서 reasoning effort의 Max를 선택할 수 있게 설정해줘.

먼저 현재 앱/계정의 라이브 model/list와 %USERPROFILE%\.codex\config.toml을 읽기 전용으로 확인해서, 현재 선택 가능한 모델이 Max를 지원하는지 확인해줘.

Max가 지원되는 경우에만 config.toml을 먼저 백업하고, 기존 [desktop] enabled-reasoning-efforts 목록에 "max"를 추가해줘. 기존 설정은 유지하고 중복 [desktop] 섹션은 만들지 마. 레지스트리, 앱 패키지, 실행 파일, CLI 백엔드는 수정하지 마.

설정 후 Codex 앱을 재시작하도록 안내하고, 새 작업에서 Max가 실제로 선택되는지 확인해줘. Max를 지원하지 않으면 설정은 변경하지 말고 이유만 알려줘. 민감한 값은 출력하지 마.

버튼을 누르면 위 요청 문구가 클립보드에 복사됩니다.

중요: 설정 파일은 선택기 노출을 조정할 뿐입니다. 해당 PC의 앱 버전, 로그인 계정, 선택 모델이 Max를 지원하지 않으면 강제로 사용할 수 없습니다.
03

확인 기준

성공재시작 후 새 작업의 reasoning 선택기에서 Max를 선택할 수 있고, 새 세션의 실제 effort 값도 max로 기록됩니다.
정상적인 제한현재 계정 또는 선택한 모델의 라이브 카탈로그에 Max가 없으면 표시되지 않을 수 있습니다. 이 경우 설정 변경으로 권한을 만들 수는 없습니다.
참고모델 선택기는 라이브 model/list가 반환하는 모델별 지원 reasoning 옵션을 기준으로 확인하는 것이 안전합니다.
