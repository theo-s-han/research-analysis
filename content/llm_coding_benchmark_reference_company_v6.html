Coding Agent 벤치마크

AA Coding Agent Index

종합 지수

Artificial Analysis가 여러 Coding Agent 평가 결과를 결합해 제공하는 종합 지수.

평가 대상: Coding Agent의 종합 소프트웨어 엔지니어링 성능

평가 방식: 복수의 Coding Agent 벤치마크 결과를 결합해 하나의 지수로 산출

해석: 점수가 높을수록 여러 유형의 개발 작업에서 평균적으로 높은 성능을 보임

비고: 순수 모델 성능뿐 아니라 Agent harness와 실행 설정의 영향을 받을 수 있음

평가 예시여러 Coding Agent에 동일한 개발 과제를 수행시킨 뒤, 장기 작업·터미널 작업·코드베이스 이해 등 여러 하위 평가 결과를 종합 비교한다.
이 지표가 중요한 경우Codex, Claude Code, Gemini CLI처럼 서로 다른 Coding Agent의 전반적인 개발 성능을 한눈에 비교할 때 중요하다.

DeepSWE

Long-horizon SWE

실제 오픈소스 저장소에서 장기간에 걸친 기능 구현 및 버그 수정 능력을 평가하는 소프트웨어 엔지니어링 벤치마크.

요구사항
- 기존 JSON parser 유지
- YAML 지원 추가
- sync / async API 모두 지원
- 기존 테스트 유지
- 신규 테스트 추가

Agent가 해야 할 일
repo 분석 → 관련 코드 탐색 → 설계 → 여러 파일 수정
→ 빌드 → 테스트 → 실패 수정 → 최종 완료

평가 대상: 장기 소프트웨어 엔지니어링 작업 수행 능력

평가 방식: 실제 오픈소스 저장소에서 기능 구현·버그 수정·테스트 통과 여부를 평가

해석: 점수가 높을수록 여러 단계가 필요한 장기 개발 작업을 안정적으로 완료함

평가 예시대규모 저장소에서 신규 기능을 추가하면서 여러 파일을 수정하고, 기존 동작을 유지하며 테스트까지 통과시키는 작업을 수행한다.
이 지표가 중요한 경우대규모 프로젝트에서 기능 추가, 복합 버그 수정, 여러 단계에 걸친 장시간 작업을 안정적으로 끝낼 수 있는지 판단할 때 중요하다.

Terminal-Bench

Terminal Agent

터미널 환경에서 명령 실행과 도구 사용을 통해 주어진 작업을 완료하는 능력을 평가하는 Agent 벤치마크.

$ ls
$ cat CMakeLists.txt
$ cmake -S . -B build
$ cmake --build build
$ ctest --test-dir build

# 실패 로그 분석
$ grep -R "FooParser" src/
$ git diff

# 코드 수정 후 다시 빌드 / 테스트

평가 대상: 터미널 기반 자율 작업 수행 능력

평가 방식: 명령 실행, 빌드, 설치, 디버깅, 설정 변경 등을 통해 주어진 목표 달성 여부를 평가

해석: 점수가 높을수록 터미널 환경에서 필요한 작업을 스스로 계획하고 수행하는 능력이 높음

비고: 버전별 문제 구성과 난이도가 다르므로 동일 버전끼리 비교해야 함

평가 예시빌드가 실패한 프로젝트에서 로그를 확인하고, 의존성을 설치하고, 설정 파일을 수정한 뒤 다시 빌드와 테스트를 수행해 문제를 해결한다.
이 지표가 중요한 경우빌드·설치·디버깅·환경 설정처럼 터미널 조작이 많은 개발 업무를 Agent가 자율적으로 처리할 수 있는지 판단할 때 중요하다.

SWE-Atlas

Codebase Understanding

기존 코드베이스 이해, 테스트 작성, 리팩터링 등 소프트웨어 엔지니어링 작업 능력을 평가하는 벤치마크.

평가 대상: 코드베이스 이해 및 소프트웨어 엔지니어링 작업 능력

평가 방식: Codebase QnA, Test Writing, Refactoring 등의 과제로 평가

해석: 점수가 높을수록 기존 코드 구조를 이해하고 테스트·리팩터링 작업을 수행하는 능력이 높음

평가 예시처음 보는 대규모 코드베이스에서 요청 처리 흐름을 추적하고, 관련 모듈을 찾고, 적절한 테스트를 추가하거나 구조를 리팩터링한다.
이 지표가 중요한 경우대규모 기존 프로젝트에서 코드 구조를 빠르게 파악하고, 테스트 작성이나 리팩터링까지 수행할 수 있는지 판단할 때 중요하다.

SWE-bench Verified

Classic SWE

실제 GitHub 이슈와 저장소를 기반으로 코드 수정 후 테스트 통과 여부를 평가하는 대표적인 소프트웨어 엔지니어링 벤치마크.

평가 대상: 실제 저장소의 이슈 해결 능력

평가 방식: GitHub 이슈와 repository를 제공하고 코드 수정 후 테스트 통과 여부를 확인

해석: Resolve Rate가 높을수록 실제 소프트웨어 이슈를 해결한 비율이 높음

비고: Verified 등 세부 버전에 따라 문제 집합이 다름

평가 예시실제 GitHub Issue를 읽고 원인이 되는 코드를 찾아 수정한 뒤, 기존 테스트와 신규 테스트를 통과시키는 패치를 만든다.
이 지표가 중요한 경우유지보수 프로젝트에서 실제 버그 리포트나 이슈를 읽고 정확한 패치를 만들 수 있는지 판단할 때 중요하다.

SWE-bench Multilingual

Multilingual

여러 프로그래밍 언어의 실제 저장소 이슈를 기반으로 repository-level 문제 해결 능력을 평가하는 벤치마크.

평가 대상: 다중 프로그래밍 언어 환경의 실제 저장소 이슈 해결 능력

평가 방식: C, C++, Go, Java, JavaScript, TypeScript, PHP, Ruby, Rust 등 여러 언어의 저장소 작업을 평가

해석: 점수가 높을수록 특정 언어에 치우치지 않은 repository-level 문제 해결 능력이 높음

평가 예시C++, Java, Rust, Go 등 서로 다른 언어로 작성된 실제 저장소의 이슈를 분석하고 코드를 수정한다.
이 지표가 중요한 경우여러 언어가 혼재된 제품이나 C++·Java·Rust 기반 프로젝트에서도 모델 성능이 유지되는지 확인할 때 중요하다.

코드 생성·편집 벤치마크

Aider Polyglot

Code Editing

여러 프로그래밍 언어에서 기존 소스 파일을 수정하고 테스트를 통과시키는 능력을 평가하는 코드 편집 벤치마크.

평가 대상: 다중 언어 코드 편집 능력

평가 방식: 기존 소스 파일을 수정하고 테스트를 통과시키는 방식으로 평가

해석: 점수가 높을수록 여러 언어에서 코드 수정 지시를 정확히 수행함

평가 예시기존 함수나 클래스를 요구사항에 맞게 수정하고, 불필요한 변경 없이 테스트를 통과시키도록 패치를 생성한다.
이 지표가 중요한 경우IDE나 Coding Agent에서 기존 소스 코드를 정확하게 수정하는 능력을 비교할 때 중요하다.

LiveCodeBench

Algorithm

새롭게 공개되는 프로그래밍 문제를 사용해 모델의 코드 생성 및 문제 해결 능력을 평가하는 벤치마크.

평가 대상: 신규 프로그래밍 문제 해결 능력

평가 방식: 시간에 따라 새로 공개된 문제를 사용해 코드 생성 및 실행 결과를 평가

해석: 점수가 높을수록 학습 데이터에 의존하지 않고 새로운 알고리즘 문제를 해결하는 능력이 높음

평가 예시처음 공개된 알고리즘 문제를 읽고 시간·공간 복잡도를 고려한 코드를 작성해 hidden test를 통과한다.
이 지표가 중요한 경우알고리즘 문제 해결력, 코딩테스트 성능, 새로운 문제에 대한 순수 코드 생성 능력을 비교할 때 중요하다.

BigCodeBench

Practical Function

라이브러리와 API를 활용해 현실적인 함수 구현 문제를 해결하는 능력을 평가하는 벤치마크.

평가 대상: 라이브러리/API 활용을 포함한 함수 구현 능력

평가 방식: 실제 소프트웨어 개발에 가까운 함수 구현 문제와 테스트 케이스로 평가

해석: 점수가 높을수록 여러 API를 조합해 요구사항에 맞는 코드를 구현하는 능력이 높음

평가 예시파일 처리, JSON 파싱, HTTP 요청, 데이터 변환 등 여러 라이브러리와 API를 조합해 하나의 함수를 구현한다.
이 지표가 중요한 경우실제 애플리케이션 코드처럼 여러 API와 라이브러리를 조합하는 구현 능력을 비교할 때 중요하다.

HumanEval

Legacy

함수 설명과 signature를 기반으로 코드를 생성하고 테스트 통과 여부를 확인하는 코드 생성 벤치마크.

def fibonacci(n):
    """
    n번째 Fibonacci 수를 반환하라.
    """
    # 모델이 구현

평가 대상: 함수 단위 코드 생성 능력

평가 방식: 함수 설명과 signature를 제공하고 생성된 구현이 테스트를 통과하는지 평가

해석: Pass@1 등이 높을수록 한 번의 코드 생성으로 정답 구현을 만들 확률이 높음

비고: 오래된 대표 벤치마크로 최신 상위 모델에서는 변별력이 제한적일 수 있음

평가 예시함수 설명과 signature를 제공하고, 모델이 함수 본문을 작성해 단위 테스트를 통과하는지 확인한다.
이 지표가 중요한 경우간단한 함수 단위 코드 생성 능력을 빠르게 비교할 때 참고할 수 있지만, 최신 Coding Agent의 실무 성능을 판단하기에는 제한적이다.

Tool Calling 및 종합 지수

BFCL

Function Calling

모델의 Function Calling 및 Tool Calling 정확도를 평가하는 벤치마크.

사용자:
"서울의 내일 날씨를 알려줘"

가능한 함수:
get_weather(city, date)
search_web(query)
send_email(address, body)

예시 호출:
get_weather("Seoul", "tomorrow")

평가 대상: Function Calling / Tool Calling 정확도

평가 방식: 적절한 함수 선택, 인자 생성, 다중·연속 호출의 정확성을 평가

해석: 점수가 높을수록 도구 선택과 호출 형식의 정확도가 높음

평가 예시사용자 요청에 맞는 API를 선택하고 정확한 인자를 생성해 단일 또는 연속 함수 호출을 수행한다.
이 지표가 중요한 경우Coding Agent가 빌드 도구, 검색, 데이터베이스, 외부 API 등 여러 Tool을 정확히 선택하고 호출할 수 있는지 판단할 때 중요하다.

AA Intelligence Index

General

Artificial Analysis가 여러 범주의 평가 결과를 결합해 제공하는 모델 종합 지수.

평가 대상: 모델의 전반적인 문제 해결 능력

평가 방식: 코딩, Agent, 일반 추론, 과학 추론 등 여러 평가 결과를 결합

해석: 여러 범주를 종합한 상대적 지수이며 정답률 자체를 의미하지 않음

평가 예시코딩, 과학 추론, 일반 문제 해결, Agent 작업 등 여러 평가 결과를 하나의 종합 지수로 비교한다.
이 지표가 중요한 경우코딩 외 영역까지 포함해 모델 자체의 전반적인 능력 수준을 비교할 때 참고하는 지표이며, Coding Agent 성능만 판단할 때는 보조적으로 보는 것이 적절하다.
